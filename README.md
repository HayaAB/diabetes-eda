# Diabetes EDA

This notebook contains an exploratory data analysis (EDA) of the Pima Indians Diabetes dataset.

- Data cleaning and preparation
- Analysis of target variable balance
- Relationship between pregnancies, BMI, pedigree function, age, and diabetes outcome
- Visualizations: Pie Chart, Strip Plot, Box Plots
